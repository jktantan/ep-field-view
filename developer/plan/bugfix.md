# BUG 修正计划

本页定义缺陷分级、响应时限、修复流程、回归要求与已知问题。

## 优先级与响应时限

| 优先级 | 定义                                                           | 响应       | 修复目标             |
| ------ | -------------------------------------------------------------- | ---------- | -------------------- |
| P0     | 数据错误、文本值展示错误导致业务误判；页面崩溃；npm 包无法安装 | 24 小时内  | 48 小时内发布 patch  |
| P1     | 主要组件解析失效、文本切换失效、校验异常                       | 3 个工作日 | 下一个 patch         |
| P2     | 部分组件边界情况、主题样式偏差、文档错误                       | 5 个工作日 | 下一个 minor / patch |
| P3     | 体验优化、建议、非阻塞问题                                     | 视排期     | 纳入 roadmap         |

安全漏洞按 P0 处理，并遵循最小披露原则。

## 缺陷处理流程

1. **复现**
   - 使用 playground 或最小仓库复现；
   - 记录 Vue、Element Plus、浏览器、本包版本；
   - 确认是否为宿主用法问题（缺少样式、未引入 Element Plus 等）。
2. **定位**
   - 优先检查 `src/formatters/`（值解析与组件格式化）与 `src/utils/vnode.ts`（插槽 VNode 解析）；
   - 检查 `src/components/TextFormItem.vue` 的文本模式与字段注册逻辑；
   - 检查 `src/utils/form-text.ts` 的表单文本模式同步。
3. **修复**
   - 先补一个会失败的测试，再修复；
   - 保持 API 兼容，必要时使用兼容别名；
   - 更新文档与 `CHANGELOG`。
4. **回归**
   ```bash
   pnpm check
   pnpm build
   pnpm docs:build
   ```
5. **发布**
   - patch 版本：`pnpm version patch` 后发布；
   - 在 GitHub Release 中引用 issue；
   - 严重问题在 README / 文档标注。

## 回归测试要求

- 所有值解析修复：至少一个单元测试覆盖该组件与边界值；
- 文本切换、校验相关修复：覆盖文本 → 编辑 → 文本的完整链路；
- 主题/样式修复：提供截图或在 playground 中可复现；
- 依赖升级导致的回归：运行完整测试与文档构建。

## 已知问题与规避方案

| 问题                              | 影响                                             | 规避                                                         |
| --------------------------------- | ------------------------------------------------ | ------------------------------------------------------------ |
| 文本值依赖插槽中静态声明的选项    | 远程搜索 / 异步 options 在父组件不更新时不会刷新 | 更新 options 后触发父组件重渲染；或使用 `formatter` 自行查询 |
| 自定义包装组件无法识别            | 显示原值                                         | 使用 `formatter` / `text` 插槽，或显式 `options`             |
| 文本切换会重建 `ElFormItem`       | 瞬时校验状态被清除                               | 使用 `skip-validation` 或自行管理错误状态                    |
| SSR 首屏无法观察动态 text         | 服务端只能读取初始 attrs                         | 首屏使用确定的文本模式；客户端挂载后同步                     |
| `week` 日期格式依赖 dayjs locale  | 不同语言下 `gggg[w]ww` 结果不同                  | 显式设置 `dateFormat`                                        |
| 表格内未显式 `text` 且无默认插槽  | 无内容                                           | 表格中传入 `value` + `text`                                  |
| `el-form` 的 `text` 不是正式 prop | Element Plus 未来可能变更                        | 升级计划中列为必检项                                         |

## 发布门槛

- P0 / P1 修复：必须补充回归测试；
- 任何发布：`pnpm check`、`pnpm build`、`pnpm docs:build` 全部通过；
- 发布后 24 小时内关注 issue 与下载量异常；
- 发现回归立即发布 patch 或回滚（npm 使用 `npm deprecate` 标记问题版本）。
